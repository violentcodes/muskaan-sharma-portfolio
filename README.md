# Muskaan Sharma — portfolio

A single-page portfolio site: orange and navy, heavy display type, smooth inertial scrolling, and a staggered grid of journey cards.

## Edit her details

Open `index.html` and change the `SITE` block near the bottom (name, email, LinkedIn, portfolio link, résumé file).

## Photos

Put them in `photos/`:

- `hero.jpg`: her portrait (a plain background works best)
- `1.jpg` to `5.jpg`: one for each journey card

Any photo that's missing falls back to a designed placeholder.

## Run locally

Open `index.html` through any static server, for example:

```
npx serve .
```

`ledger-3d.html` is an earlier 3D version of the site, kept for reference.
